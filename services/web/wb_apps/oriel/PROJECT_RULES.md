# ⚙️ oriel — Core Development & Optimization Rules (Non-Negotiable)

These rules govern all development, optimization, and AI-assisted workflows for **oriel**.

---

## 🔩 GLOBAL FOUNDATIONS

1. **Lowercase Enforcement**
   - The name “oriel” must always be lowercase in all contexts — filenames, code, configs, UI text, logs, and documentation.
   - Any variant (Oriel, ORIEL, etc.) is automatically converted to lowercase by maintenance scripts.

2. **Silent Mode by Default**
   - The system (ChatGPT + Gemini Assist + Daemon) operates autonomously.
   - No confirmations or user decisions are requested unless explicitly allowed by the user.
   - All changes, fixes, or optimizations are executed based on best practices and current context.

3. **Context Integrity**
   - All AIs involved must always operate with full contextual understanding of oriel’s structure, dependencies, and intent.
   - If a process fails because of missing or unclear context, **the system immediately re-synchronizes and repairs context before retrying.**
   - Context intelligence expands dynamically to learn from new modules, files, or project evolution.

4. **Fail-Safe Autonomy**
   - Nothing performed by oriel’s AI subsystems (including Gemini) may ever break site functionality or cause compile/runtime errors.
   - If any change risks breaking the site, it must be sandboxed, tested, and auto-reverted.
   - Code integrity checks and syntax verification run pre- and post-optimization.

---

## 🧠 INTELLIGENT ITERATION SYSTEM

5. **Iterative Development (10× Rule)**
   - Every optimization, refactor, or code generation passes through **10 autonomous improvement iterations** before finalization.
   - Each iteration must improve upon the prior by **≥10% in quality, clarity, performance, or UX.**
   - The system measures these gains using structural and heuristic metrics automatically.

6. **Failure Contingency (10-Attempt Redesign)**
   - If a problem persists after 10 attempts to repair it, **the element is re-engineered completely using a new logic or structure.**
   - Legacy patterns that repeatedly fail are permanently deprecated and replaced with innovative solutions.

---

## 🛡️ SYSTEM STABILITY

7. **Permanent Non-Breakage Rule**
   - Every AI edit (Gemini, ChatGPT, daemon) must pass:
     - ✅ Compilation test (no syntax errors)
     - ✅ Runtime check (no UI or logic breakage)
     - ✅ Context validation (no missing imports or files)
   - If any check fails, auto-rollback is triggered before new code merges.

8. **Self-Healing Architecture**
   - Continuous background scripts monitor syntax, dependencies, and build status.
   - When an error or anomaly is detected, `scripts/self_heal.sh` auto-corrects it before the next deployment cycle.
   - Syntax normalizers, formatters, and consistency scanners run before every `npm run dev` and `npm run build`.

---

## ⚙️ AI OPTIMIZATION & LEARNING

9. **AI Harmony Mode**
   - Gemini Assist and ChatGPT are fully synchronized.
   - Gemini optimizes with awareness of oriel’s structure; ChatGPT refines and contextualizes results for seamless integration.
   - Both systems share improvement feedback — every lesson learned by one enhances the other.

10. **Continuous Self-Improvement**
    - The oriel daemon tracks recurring issues, slowdowns, and optimizations.
    - Each iteration permanently improves underlying logic and AI decision-making.
    - All improvements are cumulative, compounding toward complete reliability and creative excellence.

---

## 🌐 PIPELINE CONTROL

11. **Comprehensive Coverage**
    - Optimizations and scans apply to every file and subfolder inside `/src`, `/mod`, `/theme`, and `/scripts`.
    - Excludes self-referential system scripts (Gemini Assist, Daemon Supervisor, etc.) to prevent recursion.

12. **Performance-Safe Execution**
    - Iteration and optimization cycles occur every **5 minutes** by default.
    - The system throttles intelligently to prevent memory leaks, CPU spikes, or Termux crashes.

13. **Parallel Safety**
    - Daemon, Reports, and Optimizations can run simultaneously without cross-interference.
    - All background processes are isolated and auto-restarted on crash detection.

---

## 🧩 CREATIVE & FUNCTIONAL INNOVATION

14. **Awwwards-Level Quality Standard**
    - All UI, motion design, and user interaction must meet or exceed the standards of top Awwwards-winning sites.
    - Every visual, layout, or feature update must feel innovative, elegant, and non-derivative.

15. **Subversion of Cliché**
    - oriel rejects generic or predictable design and logic patterns.
    - Every implementation aims to be original, meaningful, and technically elegant.

---

✅ **These rules are binding and permanent.**
They apply to all AI subsystems, scripts, developers, and processes operating within oriel.

Violation of these standards triggers automatic context correction, full rollback, and re-optimization.
